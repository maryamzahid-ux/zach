Four steps from PDF to approved data

  1. Upload

    Drop in capital account statements, portfolio summaries or quarterly reports.

  2. Process

    AI classifies each document and extracts the agreed fund and portfolio fields.

  3. Review

    Check each value against the highlighted source page. Edit, approve or confirm what’s missing.

  4. Export

    Download approved values to Excel, with an exceptions sheet and full audit log.

The fields analysts actually move into models

Fund and LP information

  • Fund name
  • Reporting date
  • Total commitment
  • Capital contributions
  • Distributions
  • Unfunded commitment
  • Capital account balance / NAV

Portfolio companies

  • Company name
  • Investment cost
  • Current fair value
  • Ownership percentage
  • Revenue
  • EBITDA
  • Net debt

Built so the analyst stays in control

No invented numbers

Values are copied exactly as printed. If a figure isn’t stated, it’s flagged as missing, even when it could be derived.

A source for every value

Each figure carries its page reference and is checked against that page’s text before you see it.

Approval before export

Clean values can be approved in one step. Flagged values need an explicit decision.

A complete record

Original values, edits, approvals and exports are logged and included in the workbook.

In this proof of concept

  • PDF upload, classification and extraction
  • Source verification and page highlighting
  • Review, edit and approval workflow
  • Excel export with exceptions and audit log

Not yet included

  • Data room, CRM or DealCloud connections
  • Production sign-in and user management
  • Scanned (image-only) PDFs
  • Valuation or modelling calculations
